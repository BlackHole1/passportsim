# セキュリティポリシー

[English](../../../SECURITY.md) | [简体中文](../zh-CN/SECURITY.md) | **日本語** | [Français](../fr/SECURITY.md)

## サポート対象のバージョン

PassportSim は 1.0 より前の段階です。セキュリティ修正は `main` と次のパッケージに入ります。古いパッケージには修正を提供しません。

## 脆弱性の報告

セキュリティ上の問題を公開の Issue やプルリクエストで報告しないでください。**bh@bugs.cc** へメールで、次の内容をお送りください。

- 問題の内容と、攻撃者がそれを使って何をできるか
- 再現する手順、入力またはファームウェアイメージ(実機のデータは含めないでください。後述)
- バージョン(`passportsim --version`)とホスト OS

3 営業日以内に受領の連絡を、10 営業日以内に評価結果をお送りします。修正の進捗をお知らせし、公開日を相談のうえ決め、希望されない場合を除いて報告者としてお名前を記載します。

## 対象範囲

エミュレーターは信頼できないファームウェアを実行し、求めに応じて実機とも通信します。次の境界をセキュリティ上重要なものとして扱います。

- **ゲストの境界。** ファームウェアがホストのファイルを読み書きすること、仮想 LAN が明示的にブリッジする範囲を超えてネットワークに到達すること、他のインスタンスに影響する形でホストプロセスをクラッシュさせることは、あってはなりません。
- **デーモン。** `passportsim serve` はループバックでのみ待ち受け、HTTP、WebSocket、MCP のすべてのリクエストに、所有者だけが読めるトークンか Web UI のワンタイム起動コードが必要です。どちらかを回避できる方法は脆弱性です。
- **実機への書き込みツール。** `flash_device` は最初にフラッシュをバックアップし、デバイスを識別する領域を書き込み・消去せず、チップ全体を消去せず、eFuse を焼きません。これらを行わせる入力は脆弱性です。
- **秘密情報。** デバイスのデータ(MAC アドレス、固有 ID、カードの内容、フラッシュや eFuse のダンプ、バックアップ名)は、ツールの出力、ログ、成果物、リポジトリ、パッケージのいずれにも現れてはなりません。
- **パッケージ。** パッケージにビルドマシンのアカウントのパスや、シークレットガードが拒否するものを含めてはなりません。

## 対象外

- エミュレートされたファームウェア自体のバグや、エミュレーターと実機の動作の違い。これらは忠実度の問題なので、通常の Issue を作成してください。
- ホスト上であなたのユーザーとしてすでにコードを実行できることが前提の攻撃。
- 無限ループや自身のメモリの使い切りを起こすファームウェア。`run` には時間の上限を指定できます。

## 報告に含めるデバイスデータ

実機から取得したフラッシュダンプ、eFuse ダンプ、バックアップ、ログは添付しないでください。報告にそれらが必要な場合はその旨を伝えていただければ、非公開の連絡手段を相談します。[secrets.md](secrets.md) も参照してください。
